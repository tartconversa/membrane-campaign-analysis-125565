# 资料口径

主体、设备和数值全部合成，不代表真实企业或实验结果。CSV 为 UTF-8，空值表示未知或不适用，不能当成零；布尔为 true/false。日期采用 ISO 格式，时刻带 +08:00 时区；日期区间左闭右开。金额为人民币元，概率为 0–1，除字段另有声明外数量为非负。CSV 排序不代表事件顺序。available_at 表示该事实最早可知时刻，历史截点不可使用较晚才知的值。样本用于开发，业务结论未预设。

recipe为离散候选，不含需要发明的化学配方。batch为独立制备批，coupon为该批切片，area_cm2为实物面积；切片损耗为每次切割2平方厘米。yield_state的failed为制造失败，不能把未测性能补成零。conductivity为毫西门子每厘米，crossover为每天渗透比例，durability为循环数，cost为元每平方米。bench与stack量纲相同但测量层级不同；stack前置条件为同一批已有bench conductivity且crossover记录，耐久结束切片不可复用。候选晋级至少考虑联合指标与制造可重复性，门槛是用户条件，不指定建模算法或获胜候选。

## recipes
候选路线。

记录键：['recipe_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| recipe_id | string | 候选 |
| route | string | 路线 |
| material | string | 原料 |
| cost_m2 | number | 每平方米成本 |

## batches
制造成功失败均保留。

记录键：['batch_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| batch_id | string | 批 |
| recipe_id | string | 候选 |
| made_at | date | 制备 |
| gross_area_cm2 | number | 制备面积 |
| yield_state | string | 制造结果 |
| available_at | datetime | 可知 |

## coupons
已切片库存，切片前母材余额另列。

记录键：['coupon_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| coupon_id | string | 试样 |
| batch_id | string | 批 |
| area_cm2 | number | 面积 |
| state | string | used或available |
| destroyed | boolean | 试验后破坏 |

## results
部分实验尚无最终指标。

记录键：['result_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| result_id | string | 结果 |
| coupon_id | string | 试样 |
| fidelity | string | bench或stack |
| metric | string | 指标 |
| temperature_c | number | 温度 |
| current_density | number | 电流密度 |
| value | number | 值或未知 |
| state | string | running或finished |
| available_at | datetime | 可知 |

批次剩余母材面积，等于成功批毛面积减三片及切损。

记录键：['batch_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| batch_id | string | 批 |
| remaining_area_cm2 | number | 未切余量 |
